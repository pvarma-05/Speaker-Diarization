=====================================
  DEMO 1: PRE-RECORDED DATA
  Speaker Authorization Pipeline
=====================================

This demo uses existing test data to show how the pipeline
identifies authorized speakers and filters out unauthorized ones.


SETUP (Do this BEFORE demo day)
===============================

1. Open PowerShell and navigate to the project:

   cd R:\capstone\Speaker-Diarization

2. Activate the virtual environment:

   venv\Scripts\activate

3. Verify Python and packages are working:

   python -c "import torch; import whisperx; import pyannote.audio; print('All good!')"

4. Set your HuggingFace token (if not in .env file):

   $env:HF_TOKEN = "your_token_here"

5. **CRITICAL — Re-enroll speakers on THIS machine:**

   Voiceprint embeddings must be computed locally.
   The pre-built registry won't work on a different machine.

   python scripts/setup_speakers.py

   You should see: Alice, Bob, Charlie enrolled successfully.
   This only needs to be done ONCE per machine.


LIVE DEMONSTRATION STEPS
========================

Step 1: Show the Speaker Registry
----------------------------------
"First, let me show you who is authorized in our system."

   python scripts/enroll_speaker.py --list

Expected output:
   Enrolled speakers (3):
   ----------------------------------------
     • Alice  (source: ...)
     • Bob    (source: ...)
     • Charlie (source: ...)


Step 2: Explain the Test Audio
------------------------------
"We have a 6-minute conversation with 5 speakers.
 3 are authorized (Alice, Bob, Charlie) and 2 are
 unauthorized (Frank, Grace). The system should only
 transcribe the authorized speakers."


Step 3: Run the Pipeline
------------------------
"Now let's run the pipeline on this conversation."

   python main.py data/long_conversation.wav --output results/demo_output.json

Wait for the pipeline to process (~2-3 minutes).

Expected output highlights:
   Step 6: Speaker authorization filter...
     ✓ Authorized 42/68 segments
     ✗ Filtered out 26 segments from 2 unauthorized speaker(s)


Step 4: Show the Results
------------------------
"As you can see, the system correctly identified all 3
 authorized speakers and completely filtered out the 2
 unauthorized speakers. Zero false acceptances."

Open results/demo_output.json to show the clean transcript
with only Alice, Bob, and Charlie's segments.


Step 5: Show Performance Stats (Optional)
------------------------------------------
"Our benchmark shows 96.7% accuracy on clean audio,
 and the system fails safe under noise — it rejects
 everyone rather than accepting an imposter."


TROUBLESHOOTING
===============
- If "Failed to load diarization pipeline": Check HF_TOKEN
- If it's slow: First run downloads models (~1-2 GB)
- If no speakers found: Run setup_test_data.py first
